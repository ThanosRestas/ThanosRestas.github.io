# Thanos Restas — Portfolio

Static portfolio with professional projects, personal projects, and an expanded resume. Built with HTML, CSS, and plain JavaScript.

## Preview

Open `index.html` in a browser, or run `python -m http.server 8000` and visit http://localhost:8000.

## Content

Edit `content.js` for projects, `app.js` for page templates and resume content, and `styles.css` for appearance. Routes use query parameters, including `?page=resume`, `?page=personal`, and `?project=ignite`.

The downloadable resume is `Thanos_Restas_CV.pdf`. `Profile.pdf` is local reference material and is not committed or published. Project artwork is intentionally placeholder artwork.

## Deployment

GitHub Pages publishes the root of the `main` branch at https://thanosrestas.github.io/. Push updates to `main` to deploy. `.nojekyll` enables plain static publishing. The repository is private; the website is public.
